# 💇‍♀️ HairSalonBot (Telegram Bot + Web Admin Panel)

Интерактивная система онлайн-записи для парикмахерской со встроенной административной панелью.

## Технологический стек:
- **Бэкенд:** C# (ASP.NET Core)
- **База данных:** PostgreSQL (с использованием Entity Framework Core)
- **Фронтенд админки:** HTML5, CSS3 (Bootstrap), JavaScript Fetch API
- **API мессенджера:** Telegram.Bot Library

## Функционал:
- Автоматическая регистрация пользователя по номеру телефона при старте.
- Интерактивная запись (выбор услуги, выбор мастера, выбор времени).
- Валидация вводимых пользователем данных по "белому списку" свободных слотов.
- Административная веб-панель для просмотра активных записей и удаления записей.
- Безопасность: Админка защищена Cookie-авторизацией.
